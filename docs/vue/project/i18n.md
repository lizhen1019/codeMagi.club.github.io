# Vue 国际化

🎓 简单实现项目的国际化配置

## 1. 国际化配置

### 1.1. 安装

```bash
yarn add vue-i18n@latest    # 要安装就安装最新版
```

### 1.2. 配置

首先新建 `src/i18n/index.js` 文件，里面配置国际化内容。

```js
// i18n/index.js
import { createI18n } from "vue-i18n";
import en from "./locale/en.json";
import zh from "./locale/zh.json";

// 类型检查的配置对象
const i18nConfig = {
  legacy: false, // 必须关闭Vue2兼容模式
  locale: navigator.language.split("-")[0] || "zh", // 自动检测浏览器语言
  fallbackLocale: "en", // 回退语言
  globalInjection: true, // 全局注入$t方法
  messages: { en, zh },
  pluralizationRules: {
    // 复数规则
    ru: function (choice) {
      // 俄语复数规则
    },
  },
};

export default createI18n(i18nConfig);
```

语言 JSON 文件：`src/i18n/locale/zh.json`

```json
{ "hello": "你好" }
```

### 1.3. 注册 i18n 插件

在`main.js`中注册 i18n 插件。

```js
import { createApp } from "vue";
import App from "./App.vue";
import i18n from "./i18n";

const app = createApp(App);
app.use(i18n);
app.mount("#app");
```

### 1.4. 监听语言切换

在 `App.vue` 中监听语言切换事件，切换语言。

```js
import { useI18n } from "vue-i18n";
import { watchEffect, ref } from "vue";

const { locale } = useI18n();
// 初始化时读取存储
watchEffect(() => {
  const savedLang = localStorage.getItem("lang");
  if (savedLang) {
    locale.value = savedLang;
  }
});
```

### 1.5. 切换语言与使用

在组件中使用 `$t` 方法获取国际化内容。

```vue
<template>
  <button @click="changeLanguage('en')">{{ $t("c.i.0") }}</button>
  <button @click="changeLanguage('zh')">{{ $t("c.i.1") }}></button>
</template>
<script setup>
import { useI18n } from "vue-i18n";
import { watchEffect, ref } from "vue";
const { locale } = useI18n();
import i18n from "../../i18n/index";
const { t } = i18n.global;
// 切换逻辑
const changeLanguage = (lang) => {
  console.log(t("c.i.0"));
  locale.value = lang;
  localStorage.setItem("lang", lang); // 持久化存储
};
</script>
```

## 2. VS Code 插件
